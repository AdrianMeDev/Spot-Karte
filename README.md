# SpotMap 🗺️

**Discover, save and share interesting places and events.**

SpotMap is a location-based web application where users can discover and share interesting spots on an interactive map.

A spot can be either:
- **Places:** Restaurants, cafés, landmarks, viewpoints, hiking trails or other interesting locations.
- **Events:** Upcoming or ongoing events such as concerts, festivals, sports events, markets or local meetups.

## Features

- Explore spots on an interactive map.
- View spot details, including name, description, category and location.
- Filter spots by category.
- Find spots within a specified radius.
- Create new spots by clicking on the map.
- Authenticate users via Keycloak.
- Edit and delete your own spots.
- Admins can manage all spots.

## Tech Stack

- **Frontend:** Angular, TypeScript, Leaflet
- **Backend:** Python, Django, Django REST Framework
- **Database:** PostgreSQL, PostGIS
- **Authentication:** Keycloak
- **Infrastructure:** Docker, Docker Compose

## Project Goal

Build a full-stack geospatial application while deepening practical knowledge of modern web development, REST APIs, spatial databases, authentication and containerization.
